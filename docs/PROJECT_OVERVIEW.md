# CN Free Token Hub · 项目背景与设计文档

> **项目名称**：CN Free Token Hub（国内模型免费 API 额度雷达）  
> **线上访问地址**：[https://nasated.github.io/cn-free-token-hub/](https://nasated.github.io/cn-free-token-hub/)  
> **GitHub 仓库**：[https://github.com/nasated/cn-free-token-hub](https://github.com/nasated/cn-free-token-hub)  
> **定位**：专注中国境内可用、且 API 可直接编程调用的免费大模型额度资讯站，每日定时自动核验更新。

---

## 一、 项目背景与核心痛点

随着国内大语言模型（LLM）生态的爆发式演进，各大厂商（阿里、智谱、月之暗面、DeepSeek、腾讯、科大讯飞、零一万物等）纷纷面向开发者推出了不同程度的“新人免费额度”、“公测免费体验包”以及“特定模型永久免费调用”政策。

但在日常开发与尝鲜过程中，开发者普遍面临以下**四大痛点**：

1. **信息极度分散，难以全局比价**：
   各平台的优惠政策隐藏在复杂的控制台、帮助文档或短期活动页中，开发者需要逐个注册、翻找、比对有效期限，耗费大量精力。
2. **“假免费”与“非 API 额度”陷阱**：
   市面上许多模型导航站混杂了大量仅能在 Web 网页版或手机 App 端对话消费的“个人积分/代币”，这些额度根本无法用于代码或开发环境中的 API 调用。
3. **海外模型门槛高、支付受限**：
   许多收录站大量混杂 OpenAI、Anthropic、Google 等海外 API。这些平台往往需要外币信用卡绑定、特定网络环境或容易触发风控封号，对国内常规业务与个人开发者极不友好。
4. **额度政策时效性短、变更频繁**：
   免费额度的赠送数量、有效期限经常随厂商策略突发调整（例如由 30 天调整为 90 天，或者特定模型从付费转为免费公测）。人工维护的博客或静态文章往往上线数周后即告失效。

**CN Free Token Hub 正是为彻底解决上述痛点而诞生的项目。**

## 二、 核心收录原则

本项目在设计之初确立了严密的收录边界：

- ✅ **纯中国境内开放平台**：国内网络直连，无需代理，无风控锁卡隐患。
- ✅ **100% 必须 API 可直接编程调用**：必须提供标准 HTTP API 或兼容 OpenAI SDK 的调用方式；纯网页对话积分一律不收录。
- ✅ **清晰标明实名与有效条件**：明确区分“免实名直接领用”与“需实名认证”，详细展示资源包有效期。
- ✅ **中立客观、不做价值主观评判**：不评判模型智商高低，只客观呈现免费额度规格、适用模型范围及官方来源依据。

### 1. 技术栈清单
- **核心框架**：Next.js 15（App Router，纯静态导出）
- **语言**：TypeScript 5
- **样式系统**：Tailwind CSS + 原生 CSS 变量（轻量且完美支持深浅主题）
- **爬虫核验**：Node.js + TSX 原生 Fetch（带浏览器头伪装与重试）
- **CI/CD**：GitHub Actions（最小权限流水线）
- **托管平台**：GitHub Pages（免服务器、免数据库、全球 CDN 加速）

## 四、 仿 aihot.news 的 UI 与交互哲学

在视觉与交互设计上，项目全面向科技资讯聚合标杆 **[aihot.news](https://aihot.news/)** 看齐：

1. **经典 App Shell 架构**：
   - **PC 端左侧固钉侧边栏（Sidebar）**：集成品牌 Logo、更新呼吸灯、发现导航（精选热门、全部额度、免实名专区、永久免费、额度日报、我的收藏）、模型分类索引、深浅色模式切换器。
   - **移动端悬浮底栏（Mobile TabBar）**：在手机屏幕上提供如 App 般的极简触控切换。
2. **双视图自由切换（Dual View Modes）**：
   - **条目资讯流（Stream View）**：aihot 标志性的新闻列表形态，包含排行金标（`01`、`02`、`03`）、醒目额度金色大字、政策摘要描述、属性胶囊与一键直达/复制。
   - **卡片矩阵（Grid View）**：自适应多列网格卡片，适合桌面大屏横向浏览。
3. **质感配色与模式**：
   - **浅色模式**：自然温润的米暖白底色（`#faf9f6`），柔和护眼；
   - **深色模式**：深冷墨炭黑底色（`#13191c`），高对比度且不刺眼；
   - **品牌点缀**：采用 aihot 标志性的琥珀金（`#d97706` / `#f59e0b`）作为额度核心要素的高亮。
4. **人性化交互细节**：
   - **已读状态记录（`fc-read`）**：点击过的平台条目自动柔和变暗，避免反复浏览干扰；
   - **星标收藏（`Starred`）**：用户可以点击小星星收藏平台，随时在侧栏一键调出专属常用列表；
   - **即时搜索（Instant Search）**：支持中文名、英文名、技术标签（如 Qwen、代码、长文本）秒级无刷新过滤。

## 五、 部署与域名说明

- **默认模式（当前状态）**：
  使用 GitHub Pages 分配的二级域名 `https://nasated.github.io/cn-free-token-hub/`。无需配置服务器、无需付费购买域名即可直接在手机和电脑浏览器中高速访问。
- **自定义独立顶级域名（可选）**：
  若希望拥有类似 `aihot.news` 这样独立的顶级域名（如 `tokenhub.news` 或 `freetoken.cn`），系统已预留完整支持，仅需在域名注册商处做一条 CNAME 记录即可无缝接入。
